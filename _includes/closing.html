{%- assign t = site.data.i18n[page.lang] -%} {%- comment -%} The panel is inverted in light mode (`bg-neutral`) but NOT in dark. In cm-dark, `--color-neutral` is deliberately lighter than `--color-base-100` so daisyUI's soft variants keep contrast — which makes it a soft-surface token, not a panel token. Using it as a full panel in dark mode put near-white `neutral-content` on a 55%-lightness grey: 3.77:1, which fails AA for body text. In dark mode the panel becomes a raised base-200 surface instead. Do not collapse these back to a single set of classes. {%- endcomment -%}
